# Задание 1

### Текст задачи
Разработать консольное приложение с дружественным интерфейсом с возможностью выбора
заданий для работы с «базой данных (БД)», хранящейся в бинарном файле. Перечень полей
(минимум 5), достаточно полно характеризующих заданную в варианте предметную область,
предложить самостоятельно (постараться отразить в перечне полей такие, которые требуют разных
типов данных). Приложение должно выполнять следующие функции:
1. Чтение базы данных из бинарного файла.
2. Просмотр базы данных.
3. Удаление элементов (по ключу).
4. Добавление элементов.
5. Реализация 4 запросов (формулировки запросов придумать самостоятельно). 2 запроса
должны возвращать перечень, 2 запроса одно значение.
В классе должны присутствовать свойства, конструкторы, перегруженный метод ToString(). Весь
функционал приложения реализовать в виде методов вспомогательного класса с помощью LINQзапросов.
Предусмотреть обработку возможных ошибок при работе программы.
Пункт 5 оценивается в 2 балла, остальные пункты по 1 баллу. Максимально за лабораторную работу
можно получить 6 баллов. Каталог услуг.

### Алгоритм решения
Попадаем в Main. Устанавливаем кодировку вывода UTF-8. Создаём пустой List<ServiceRecord>. Заводим флаг exit = false. Запускаем цикл while (!exit).
В цикле выводим меню из 10 пунктов (загрузка, просмотр, удаление, добавление, 4 запроса, сохранение, выход). Читаем выбор пользователя через Console.ReadLine(). Оборачиваем switch в try/catch — при любом исключении выводим сообщение «Ошибка: …».
ServiceManager.LoadFromFile(FilePath). Если файла нет — возвращаем пустой список. Иначе открываем BinaryReader, читаем количество записей, в цикле читаем все поля через ReadInt32, ReadString, ReadDecimal, ReadDouble, ReadBoolean, ReadInt64 (дата через DateTime.FromBinary). Возвращаем список, выводим количество загруженных записей.
ServiceManager.PrintRecords(records). Если список пуст — выводим «Записи отсутствуют». Иначе печатаем каждую запись через ToString().
запрашиваем ID через InputHelper.ReadInt. Вызываем DeleteByKey: ищем запись через FirstOrDefault, если нет — сообщение, если есть — Remove и сообщение об удалении.
ServiceManager.AddRecord(records). Запрашиваем ID, проверяем на дубликат через Any. Затем запрашиваем название, категорию, цену, длительность, доступность, исполнителя, дату — каждый раз через соответствующий метод InputHelper. Добавляем новую ServiceRecord в список.

запрашиваем категорию. QueryByCategory через LINQ фильтрует по категории (без учёта регистра), сортирует по цене, возвращает список. 

запрашиваем максимальную цену. QueryAvailableCheaperThan фильтрует по IsAvailable && Price <= maxPrice, сортирует по цене. 

запрашиваем категорию. QueryAveragePriceByCategory выбирает цены категории, если есть — возвращает среднее, иначе 0. Выводим с двумя знаками после запятой.

запрашиваем исполнителя. QueryCountByProvider считает количество записей с этим исполнителем (без учёта регистра). Выводим число.

ServiceManager.SaveToFile(FilePath, records). Открываем BinaryWriter на создание, пишем количество записей, затем для каждой — все поля в том же порядке, что и при чтении, дата через ToBinary(). Выводим «БД сохранена».

exit = true, цикл завершается, программа заканчивается. Default — сообщение «Неверный пункт меню».
